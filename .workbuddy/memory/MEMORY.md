## 分析方法论约束（用户2026-08-05/07反馈，重要）
- **禁止事后归因叙事**：不能先看到今日涨跌结果，再倒推K线找论据解释。预测性判断须事前写下预判+触发条件+止损条件，事后用结果验证。
- **事实描述 vs 因果断言要分清**：拉取的数据（价格、量、涨跌）是事实；对"为什么涨/跌"的归因须标注为"假设"而非"结论"。
- **基础规则**：创业板30开头±20%、科创板68开头±20%、北交所±30%、主板±10%。涨跌幅口径=昨收→今收。
- **诚实优先**：犯错时直接承认，不掩盖。曾把创业板+10%误当"涨停"被纠正。
- **系统定位=分析工具，非实盘执行**：引擎是因子打分+排名+形态扫描的参考层。引擎输出的"信号追踪胜率"是系统内部模拟，**非用户账户真实盈亏**。禁止把内部数据当实盘表现诊断、或对用户实盘盈亏归因。

## 体系架构
- **ISIR**：主评分（ICIR_V3权重，33因子ICIR标定）
- **GLM**：ISIR优化版，防过度集中（ICIR_GLM权重，mfi/pct_52w取反）
- **SS分**：独立传统技术评分（技术35%+资金55%+信息5%+事件5%）
- **共识** = ISIR ∩ GLM ∩ SS分排名（三体系）
- **超跌反弹(第四体系)**：独立标记，不参与共识。评分=超跌30+反弹35+趋势确认20+风控15，含ATR动态止损+阶段标注(初现/确认/加速)。**2026-09-14起HTML不再单独展示(用户决定)，计算保留作第五视图输入**；第四体系tab已从报告移除
- **质量反弹(第五视图, 2026-09-14, 用户指定替代第四体系展示)**：超跌反弹有效 ∩ (ISIR或GLM排名≤150, QR_THRESHOLD常量)。均值回归逻辑，与三体系动量方向相反。180日回测: 20日胜率55.5%/均+6.4%(vs纯超跌49.8%/+2.2%)，**5日无优势必须持有20日**，多头日最强(+9~10%)，加速阶段最差勿追。条件叠加无增益(cross150已是最优, 更严≠更好；共识∩超跌=接飞刀8.3%胜率)。回测脚本quality_rebound_backtest.py，结果存output/quality_rebound_backtest.json由引擎自动渲染。空头日纯超跌确认阶段更强(67.5%)的分工结论因用户选择单一视图而不再日常可见，但数据在回测JSON中保留
